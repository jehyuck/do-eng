## 원장 기록 규칙

- 본 실험 실행 전 새 실행 ID를 먼저 발급한다.
- 조건이 하나라도 바뀌면 별도 실행으로 기록한다.
- 실패·중단·제외 실행도 삭제하지 않는다.
- 실행 명령에서는 secret과 실제 토큰 값을 마스킹한다.
- 원시 결과는 `experiment/results/{실행 ID}/` 아래에 보존한다.
- 요약 문서만 있고 원시 결과가 없으면 `검증 필요`를 표시한다.
- smoke test는 본 실험과 분리하고 성능 결론에 사용하지 않는다.
